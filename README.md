# Незанавешенное — лонгрид


- `index.html` — разметка и финальный блок «Под домом»
- `css/fonts.css` — шрифты Literata (обычная, курсив, полужирная) и IBM Plex Mono, встроены в CSS
- `css/style.css` — стили
- `js/story.js` — раскадровка: камеры, кадры, тексты (компьютер 1440×900 и телефон 390×844)
- `js/app.js` — движок: sticky-сцена, камера, перетекание кадров, построчный текст, ворона
- `js/lenis.min.js` — плавная прокрутка колёсиком (Lenis, MIT)
- `img/` — кадры из Figma (`d/` компьютер, `m/` телефон, `w/` фасад целиком), ворона
- `fonts/` — Literata и IBM Plex Mono (SIL Open Font License)
